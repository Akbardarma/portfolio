Custom KiCad Controller PCB 2-Layer FR4

📡 Arsitektur Dual-ESP32 via UART 115.200 bps: ESP32 Master (Web Server AP 192.168.4.1 / Swerve) terhubung ke ESP32 Shooter (PWM 20kHz / Pitch-Yaw) via bus UART dua arah dengan watchdog timer 3 detik dan antarmuka HMI telemetri Flutter.
